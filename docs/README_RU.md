## Рекомендуемый следующий тест: Standalone v5.6 без родительского шаблона

[**Скачать v5.6 YAML**](../templates/securepoint-utm-standalone-v5.6.yaml) · [Полная инструкция перехода и отката](V5_6_STANDALONE.md)

Standalone v5.6 **не связан** с `Network Generic Device by SNMP`. В нём собственный мониторинг интерфейсов (RX/TX, статус, скорость, ошибки/discards), 4 вкладки Dashboard, CPU/RAM, VPN, сервисы, прошивка и лицензия. Добавлены уведомление при отсутствии SNMP-данных 15 минут и отключённый по умолчанию триггер падения критически важного интерфейса.

**Переключение с v5.5:** импортируй v5.6 как НОВЫЙ шаблон; затем в Host `Firewall` — Unlink and clear старого `Securepoint UTM Unified v5 by SNMP` (и отдельно подключённого generic, если он есть), Update; после этого привяжи `Securepoint UTM Standalone v5.6 by SNMP` и Update. **История старых Items удалится** — это согласовано пользователем. Не удаляй общий шаблон Zabbix во всей системе. Не пытайся привязать v5.6 одновременно со старым v5.5: Item Keys совпадут.

`Latest data`: обязательно проверить реальные ответы SNMP, особенно firmware/license. GitHub CI не проверяет живое устройство.


## Актуальная тестовая версия — v5.5 (интерфейсы)

**[Скачать v5.5 YAML](../templates/securepoint-utm-unified-v5.5-interfaces.yaml)** · [Подробная инструкция](V5_5_INTERFACES.md)

В `Securepoint UTM | Command Center` добавлена вкладка **Interfaces**. Теперь одновременно показываются **все обнаруженные интерфейсы**: состояние (Up/Down), административный статус, скорость линка, RX/TX, ошибки и отброшенные пакеты. Графики трафика и ошибок доступны отдельно для каждого интерфейса. Добавлены 7 узких IF-MIB Item Prototypes, прежние показатели и триггеры лицензии/прошивки из v5.4 сохранены.

Старый отдельный Dashboard **Network interfaces** наследуется от стандартного `Network Generic Device by SNMP`. **Просто импортом нашего YAML удалить его нельзя.** Не удаляй родительский шаблон или накопленные Items. Если захотим убрать только Dashboard, сначала посмотрим, кто ещё использует этот родительский шаблон: удаление Dashboard у родителя затронет все хосты. Безопасные варианты описаны в [V5_5_INTERFACES.md](V5_5_INTERFACES.md).

Для импорта: `Data collection → Templates → Import`, Update existing и Create new включены, **Delete missing выключен**. Заново подключать Firewall не надо. Подожди два SNMP-опроса для показателей в секунду и проверь ошибки `Not supported` в Items.


## v5.4 — Прошивка и лицензия, новые уведомления

**[Шаблон v5.4](../templates/securepoint-utm-unified-v5.4-firmware-license.yaml)** · [Описание и проверка](V5_4_FIRMWARE_LICENSE.md)

Вкладка **VPN & Security** содержит версию прошивки, новую версию по данным Securepoint SNMP, тип лицензии и оставшиеся дни. Добавлены триггеры: сообщение производителя о другой доступной версии, предупреждение за 30 дней и срочное предупреждение за 7 дней. Интерпретация ровно 0 дней включается отдельно: `{$SP.LICENSE.ZERO.IS.EXPIRED}=1`. Макросы предупреждений по лицензии и прошивке теперь включены (`=1`), но без живых SNMP-значений события могут не появиться. Требуется проверка `Latest data`.

**Импорт:** Update existing + Create new, Delete missing выключен. Email/Teams-уведомления требуют отдельно настроенной Action в Zabbix. Версии сравниваются как строки, а не численно.

## Единый шаблон v5 — кандидат, ещё не для продакшена

[Скачать YAML из GitHub](../templates/securepoint-utm-unified-v5.yaml) · [Архитектура](V5_DESIGN.md) · [Обзор чужих решений](COMMUNITY_RESEARCH.md) · [Проверки](TESTING.md)

В v5 объединён производительский SNMP (службы, IPsec, OpenVPN, AV, WireGuard, лицензия, conntrack) и отобранные стандартные показатели, которые использовались в старом v3 (TCP/UDP/IP/ICMP, RAM, процессы). Для сетевых интерфейсов наследуется официальный шаблон Zabbix. Обнаружение CPU вынесено в отключённую опцию. Опасные `hrStorage`, `hrDevice` и расчёт SWAP отсутствуют.

**НЕ импортировать на рабочий Host до тестов.** GitHub CI проверяет YAML и ссылки, но не ответы реального Securepoint. MIB-файлы производителя нельзя публиковать в репозитории; пароли и сведения о клиентах также не сохраняем.


Это экспериментальный мониторинг Securepoint UTM 14.x через SNMPv3 для Zabbix 8.0.

## Как установить

1. В Zabbix должен присутствовать стандартный `Network Generic Device by SNMP`.
2. Импортируй `templates/securepoint-utm-mib-v4.yaml`. Не включай `Delete missing` для посторонних шаблонов.
3. Создай **отдельный тестовый Host**, укажи SNMP interface на IP firewall и SNMPv3 credentials в настройках Zabbix.
4. Привяжи новый шаблон. Подожди LLD и проверь `Latest data` / `Not supported`.
5. Отправляй в Issues только обезличенные ключи Item/OID, тексты ошибок и версию прошивки.
6. Не включай аварийные макросы `{$SP.*.ALERT}`, пока не доказана правильность значений на живом устройстве.

## Что есть

Система/прошивка, лицензия, conntrack, обнаружение сервисов, IPsec, OpenVPN, антивируса и WireGuard, карты значений, графики соединений и трафика WireGuard. Дополнительные потенциально проблемные проверки выключены по умолчанию. Файлы MIB Securepoint официальные, но содержат запрет на распространение без разрешения и **не включены** в репозиторий.

**Пока нет подтверждённого успешного импорта и полного SNMP-тестирования.** Не отключай старый рабочий Host ради проверки этого шаблона.
